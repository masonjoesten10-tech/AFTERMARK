02 / Historical analogues

Context, not clairvoyance

Historical comparisons should be based on measured trajectories and validated out-of-sample results.

Historical matching is not yet enabled

This initial build retrieves current public market data and produces transparent snapshot observations. It does not fabricate historical matches. A validated analogue engine requires a curated, timestamped dataset of token launches and subsequent outcomes.

Dataset required

No score or description on this page guarantees future performance. Market data can be delayed, incomplete, manipulated, or specific to one pool. Similar historical behavior is not proof that outcomes will repeat.

05 / Cohort collection

Build the market-memory dataset.

Capture the same moment across multiple tokens so later comparisons have consistent timestamps.

Batch collection is limited to 15 unique addresses per run. Successful lookups create timestamped snapshots.

Collector uses public DexScreener data and may encounter rate limits or unindexed tokens. Repeated observations are not independent samples; timestamps, token age, pool selection, and survivorship bias matter when evaluating historical patterns.
